# Electron Microscopy Datasets for Classification and Segmentation

This repository provides three electron microscopy image datasets for image classification, semantic segmentation, and instance segmentation.

## Dataset Overview

| Dataset                                          | Task                  | Number of Images | Download                                                                                           |
| ------------------------------------------------ | --------------------- | ---------------: | -------------------------------------------------------------------------------------------------- |
| Multi-Source Organelle Classification Dataset    | Image classification  |            2,236 | [Google Drive](https://drive.google.com/file/d/1C_Ye873MtEs5gao1tYdiWIgzpyW6J2t3/view?usp=sharing) |
| Multi-Source Plant Semantic Segmentation Dataset | Semantic segmentation |              394 | [Google Drive](https://drive.google.com/file/d/1axPcKAVY7rqjs6AzBqLKbWWT81C03oDA/view?usp=sharing) |
| Mouse Cardiac Volume Electron Microscopy Dataset | Instance segmentation |            1,092 | [Google Drive](https://drive.google.com/file/d/1YOquGZ6x2OzG93-cUs2QGWsektEP_Ukw/view?usp=sharing) |

## 1. Multi-Source Organelle Classification Dataset

This is a multi-source electron microscopy image dataset for an eight-class organelle classification task.

The dataset contains **2,236 images** from the following eight classes:

1. Nucleus
2. Mitochondria
3. Endoplasmic reticulum (ER)
4. Golgi apparatus
5. Cell wall
6. Chloroplast
7. Autolysosome
8. Vesicles

### Download

https://drive.google.com/file/d/1C_Ye873MtEs5gao1tYdiWIgzpyW6J2t3/view?usp=sharing

## 2. Multi-Source Plant Semantic Segmentation Dataset

This is a multi-source semantic segmentation dataset containing electron microscopy images from different plant varieties.

The dataset contains **394 images**.

### Download

https://drive.google.com/file/d/1axPcKAVY7rqjs6AzBqLKbWWT81C03oDA/view?usp=sharing

## 3. Mouse Cardiac Volume Electron Microscopy Instance Segmentation Dataset

This is an instance segmentation dataset based on a volume electron microscopy dataset of mouse cardiac muscle.

The dataset contains **1,092 images**.
